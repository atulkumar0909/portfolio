# Atul Kumar · Developer Portfolio

Single-page, mobile-first developer portfolio (dark navy `#0d1117` + electric cyan `#00d9ff`).

## Run locally

- **Option A (simplest)**: Open `index.html` directly in your browser.
- **Option B (recommended)**: Serve with Python:

```bash
python -m http.server 5173
```

Then open `http://localhost:5173`.
